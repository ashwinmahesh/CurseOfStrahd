# Eggs plan, package R1: the Village of Barovia and the road in

Built from Part C ("R1") and Part D of the 2026-10-18 easter eggs plan (kept in the owner's vault). Three winks, all
hidden where the player has to look, none in a serious scene, none moving a main flag. Every new line below was drafted
by Gemini through the ai-bridge (`brief_*.txt`, the raw replies `raw_*.reply.txt`, the bridge's message records
`raw_*.messages.json`), then edited by hand for length, canon and the Narrator's rules. All of them are unvoiced.

## Where the plan and the game differ

- The plan put the dig on "a new search spot". It is an examine prop instead, plain to see: the joke is that it needs
  a spade, and the Narrator's line says so without saying "dig here". A hidden find could not carry the check.
- The plan listed new items for R1; none was needed (the note is a codex entry, the coins are gold).
