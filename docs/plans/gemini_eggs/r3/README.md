# Eggs plan, package R3: Vallaki

Built from Part C ("R3") and Part D of the 2026-10-18 easter eggs plan (kept in the owner's vault). Six winks, all
hidden where the player has to look, none in a serious scene, none moving a main flag. Every new line was drafted by
Gemini through the ai-bridge (`brief_*.txt`, raw replies `raw_*.reply.txt`, the bridge's records `raw_*.messages.json`),
then edited by hand for length, canon and the Narrator's rules. All of them are unvoiced.

## Where the plan and the game differ

- The chalk game is on the back of an old notice board in the square, not on the cobbles: the `drawings` art hangs on a
  wall, and no floor art draws chalk. The board stands where nothing walks and no fight starts.
- The letter never names its reader (no name, no "hunter"), so Rictavio's secret stays the quest's.
