# ADR 0002: All rolls go through DiceRoller

Status: accepted (Phase 0)

- `rules/resolution/dice_roller.gd` (`DiceRoller`) is the only source of game randomness. It is seeded,
  logs every roll with a reason. Every new game and every load seeds it fresh (`Dice.reseed_random`; owner decision
  2026-10-07, superseding "a loaded game continues the same sequence"), so reloading never replays the same rolls.
  What the world holds (the Tarokka reading, treasure placement, shop stock) comes from `StoryState.playthrough_seed`
  and stays the same across loads.
- Game code uses the `Dice` autoload (`Dice.roller`). Rules code takes a `DiceRoller` parameter so tests pass their own seed.
- Cosmetic randomness (candle flicker, particles) uses a local RandomNumberGenerator and never touches DiceRoller.
